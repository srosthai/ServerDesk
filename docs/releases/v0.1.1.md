# ServerDesk v0.1.1

Database Manager is the headline feature of this release. It works over the
existing authenticated SSH connection and never exposes a database port.

## Database Manager

- MySQL, MariaDB, and PostgreSQL connections through loopback-only SSH tunnels.
- Explorer for databases, schemas, tables, views, materialized views, columns,
  indexes, constraints, routines, triggers, and sequences.
- Bounded row browser with server-side pagination, filters, sorting, and
  identity-checked insert, update, and delete.
- SQL workspace with bounded results, cancellation, typed errors, and local
  history, plus CSV import and export.
- Preview-first table, column, index, constraint, database, role, and session
  actions with dependency warnings and read-back verification.
- SQL dump export and restore with the database vendor's own tools, cleanup of
  temporary credentials, and explicit restore confirmations.
- Read-only profiles, TLS modes, least-privilege guidance, and sanitized
  operation history.

## Signed updates

ServerDesk now checks GitHub Releases for signed updates on startup and from
**Settings > Updates**. This is the first updater-capable release.

- AppImage, Windows NSIS, and macOS app bundles can download, verify, install,
  and relaunch in place.
- DEB and RPM installs show the available version and link to the release page
  for installation with `apt` or `dnf`.
- Update artifacts are verified with an embedded minisign public key before
  installation.

**Upgrading from v0.1.0:** the v0.1.0 build predates the updater and cannot
self-update. Install v0.1.1 manually once; later updater-capable releases can
be installed in place.

## Installers

- Linux: `ServerDesk_0.1.1_amd64.deb`,
  `ServerDesk-0.1.1-1.x86_64.rpm`, `ServerDesk_0.1.1_amd64.AppImage`
- Windows: `ServerDesk_0.1.1_x64-setup.exe` (per-user NSIS)
- macOS: `ServerDesk_0.1.1_universal.dmg` and `ServerDesk.app.zip`
  (universal Intel and Apple silicon)
- `install.sh`, `install.ps1`, `SHA256SUMS`, and `latest.json`

Linux and macOS command-line install:

```bash
curl -fsSLO https://github.com/srosthai/ServerDesk/releases/latest/download/install.sh
less install.sh
bash install.sh --version v0.1.1
```

Windows PowerShell:

```powershell
Invoke-WebRequest -Uri https://github.com/srosthai/ServerDesk/releases/latest/download/install.ps1 -OutFile install.ps1
Get-Content .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Version v0.1.1
```

Every download is verified against `SHA256SUMS`.

## Signing status

- Linux packages are ready to use.
- Windows and macOS builds are **unsigned**. Windows SmartScreen may warn.
  macOS Gatekeeper may block the unsigned app; allow it in **System Settings >
  Privacy & Security**, or wait for a signed release.
- The updater minisign signature is separate from Windows Authenticode and
  Apple notarization.

## Upgrade notes

- Back up the ServerDesk data directory before upgrading if you rely on the
  existing server profiles, history, and preferences.
- The local SQLite schema migrates forward automatically on first launch
  (schema version 6). Older builds cannot reverse newer migrations.
- `v0.1.0` remains published and unchanged.
- To roll back, reinstall the previous installer from the v0.1.0 release and
  restore a data backup.
