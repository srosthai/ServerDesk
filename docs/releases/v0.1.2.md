# ServerDesk v0.1.2

This release focuses on Database usability and short-screen layouts.

## Inline database editing

The Database **Data** tab now supports editing cells directly in the grid.

- Double-click a writable cell, or focus it and press Enter, to edit in place.
- Enter commits, Escape cancels, and moving focus away commits.
- Nullable cells have an explicit NULL toggle.
- Values are validated by column kind before a write is sent.
- Updates keep the stable row identity and the original-value conflict guard,
  so concurrent changes roll back instead of being overwritten.
- Generated and identity columns stay read-only.
- The full Edit row dialog remains available for multi-column changes.
- The grid refreshes after a verified commit.

## Fullscreen Database workspace

The Database workspace top bar now has a Fullscreen control.

- Expands the workspace to the whole application viewport.
- Hides the sidebar and topbar and locks background scrolling.
- Keeps the active connection, table, filters, and page state.
- Escape or **Exit fullscreen** restores the previous layout.

## Short-screen dialog scrolling

Dialogs are now constrained to the viewport instead of extending past it.

- The Add/Edit server dialog keeps its Cancel, Test connection, and Save server
  footer visible while the form body scrolls.
- Long alerts, including connection-test results, no longer push the actions
  off screen.
- Other dialogs inherit the same maximum-height and overscroll behavior.

## Installers

- Linux: `ServerDesk_0.1.2_amd64.deb`,
  `ServerDesk-0.1.2-1.x86_64.rpm`, `ServerDesk_0.1.2_amd64.AppImage`
- Windows: `ServerDesk_0.1.2_x64-setup.exe` (per-user NSIS)
- macOS: `ServerDesk_0.1.2_universal.dmg` and `ServerDesk.app.zip`
  (universal Intel and Apple silicon)
- `install.sh`, `install.ps1`, `SHA256SUMS`, and `latest.json`

Linux and macOS command-line install:

```bash
curl -fsSLO https://github.com/srosthai/ServerDesk/releases/latest/download/install.sh
less install.sh
bash install.sh --version v0.1.2
```

Windows PowerShell:

```powershell
Invoke-WebRequest -Uri https://github.com/srosthai/ServerDesk/releases/latest/download/install.ps1 -OutFile install.ps1
Get-Content .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Version v0.1.2
```

Every download is verified against `SHA256SUMS`.

## Upgrading

- AppImage, Windows NSIS, and macOS app bundle installs can update from v0.1.1
  to v0.1.2 in place.
- DEB and RPM installs do not self-update. Install the v0.1.2 package with your
  package manager.
- v0.1.0 installations predate the updater and must install v0.1.2 manually
  once.
- Back up the ServerDesk data directory before upgrading if you rely on the
  existing profiles, history, and preferences.
- Database migrations apply forward automatically on first launch. Older builds
  cannot reverse newer migrations.

## Signing status

- Linux packages are ready to use.
- Windows and macOS builds are **unsigned**. Windows SmartScreen may warn.
  macOS Gatekeeper may block the unsigned app; allow it in **System Settings >
  Privacy & Security**, or wait for a signed release.
- Updater artifacts are signed with the embedded Tauri minisign key. That
  signature is separate from Windows Authenticode and Apple notarization.
